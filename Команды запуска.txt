Помощник по конспектам информатики. Запуск на Windows.

1. Установи Python 3.10 или новее и Ollama.
2. Скачай ZIP и открой в VS Code внутреннюю папку, где лежат start.cmd и app.py.
3. В терминале PowerShell введи: .\start.cmd

Программа сама создаст окружение, поставит нужную библиотеку, запустит Ollama, скачает модель и загрузит конспекты. При первом запуске нужен интернет. Когда появится строка «Вопрос:», вводи вопросы. Для выхода напиши «выход».

Если открыт внешний каталог rag_study-main, команда будет: .\rag_study-main\start.cmd
Если файл не найден, проверь папку. Если не найдены Python или Ollama, установи их и перезапусти VS Code. Если модель не скачалась, проверь интернет и свободное место и запусти ещё раз. Не запускай app.py кнопкой Run - для обычного запуска нужен start.cmd.

В sample лежат материалы за 5-11 классы и книга по Python. Свои TXT, MD, DOCX или PDF можно положить туда же и запустить проект снова.

Веб-интерфейс: после первого запуска введи .\.venv\Scripts\python.exe web.py, затем открой http://127.0.0.1:8765. Для остановки нажми Ctrl+C.
