Локальный ИИ-помощник Qwen 2.5 3B. Запуск на Windows.

1. Установи Python 3.9 или новее и Ollama.
2. Распакуй ZIP.
3. Открой папку rag_study-main в VS Code. В этой папке должны лежать start.cmd, console.py и rag_core.py.
4. Запусти start.cmd двойным щелчком или выполни в терминале VS Code команду .\start.cmd.

При первом запуске программа создаст виртуальное окружение, установит нужные библиотеки, запустит Ollama, при необходимости скачает qwen2.5:3b и загрузит библиотеку материалов. Для первоначальной установки нужен интернет. После настройки вопросы обрабатываются локальной моделью.

По умолчанию включён автоматический режим «сначала библиотека, затем ИИ»:
- Сначала программа ищет подходящие фрагменты в библиотеке проекта.
- Если находит подходящие материалы, Qwen формирует ответ с опорой на них и показывает источники.
- Если ничего подходящего нет, консоль выводит сообщение «Подходящая информация не найдена» и «Переключаюсь на Qwen 2.5 3B», после чего модель отвечает без конспектов.

Команды чата:
/auto — автоматический режим: сначала библиотека, затем ИИ при отсутствии ответа.
/ai — прямой диалог с Qwen без поиска по библиотеке.
/rag — поиск по библиотеке и передача подходящих фрагментов Qwen; если ничего не найдено, используется ИИ.
/docs — показать список загруженных материалов.
/new — очистить историю разговора.
/help — показать команды.
/exit — выйти из программы.

Свои TXT, MD, DOCX или PDF можно добавлять в папку sample. После перезапуска проекта материалы будут заново загружены в библиотеку.

Если Python или Ollama не найдены, установи их и перезапусти VS Code. Если модель не скачалась, проверь интернет и свободное место и запусти start.cmd ещё раз. Не запускай app.py кнопкой Run для работы с консольным чатом — используй start.cmd.
