Практика Python. Частые школьные задачи.

Проверить четность числа можно условием `n % 2 == 0`. Сумму цифр положительного числа удобно находить циклом: брать остаток от деления на 10 и затем делить число на 10 нацело. Для подсчета частот слов подходит словарь или `Counter` из `collections`. Для удаления повторов подходит множество, если порядок не важен.

Для поиска максимального элемента готового списка используй `max(values)`, для минимума - `min(values)`, для суммы - `sum(values)`. Для среднего значения проверь, что список не пуст, затем раздели сумму на длину. Для сортировки списка чисел есть `sorted(values)`. Для сортировки слов по длине используй `sorted(words, key=len)`.

Квадратное уравнение `ax^2 + bx + c = 0` при `a != 0` решают через дискриминант `d = b*b - 4*a*c`. Если d < 0, действительных корней нет. Если d = 0, корень один: `-b/(2*a)`. Если d > 0, корни равны `(-b + sqrt(d))/(2*a)` и `(-b - sqrt(d))/(2*a)`; `sqrt` берут из модуля `math`. Перед вычислением нужно отдельно проверить случай a = 0.
