Python. Условия и циклы.

Условие if выполняет блок, когда выражение истинно. elif проверяет следующую ветку, else выполняется, когда предыдущие проверки не прошли. Например: if score >= 60: print('зачет') else: print('повтори тему'). В реальном файле строку после if и строку после else нужно писать с отступом.

Цикл for перебирает последовательность. Пример: for item in [1, 2, 3]: print(item). range(5) дает 0, 1, 2, 3, 4; range(2, 6) дает 2, 3, 4, 5; range(0, 10, 2) дает четные числа меньше 10. enumerate(items) возвращает пару из индекса и элемента. zip(a, b) перебирает две последовательности парами.

Цикл while повторяется, пока условие истинно. Счетчик или другое изменяемое состояние должны приблизить цикл к завершению, иначе получится бесконечный цикл. break сразу прекращает цикл, continue переходит к следующему повторению. Блок else после цикла выполняется, если цикл завершился без break.

Для задач на сумму и количество удобно завести переменную-накопитель. Например, total = 0, затем внутри цикла total += value. Для поиска максимума можно использовать max(values), а для проверки условия у всех элементов - all(values). Короткие встроенные функции часто яснее ручного цикла.
