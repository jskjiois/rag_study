Python. Выражения включения, итераторы и генераторы.

Списковое включение создает список из последовательности: squares = [x * x for x in range(5)]. Можно добавить условие: evens = [x for x in range(10) if x % 2 == 0]. Для словаря есть выражение вида {x: x * x for x in range(5)}, для множества - {x * x for x in range(5)}. Если выражение становится сложным, обычный цикл легче читать.

Итерируемый объект можно передать в for. Итератор выдает значения по одному; функция iter получает итератор, next берет следующее значение. Когда значения заканчиваются, возникает StopIteration. Генераторная функция использует yield вместо return для выдачи последовательности по частям. Генераторное выражение выглядит как (x * x for x in range(5)) и не создает весь список сразу.

Генераторы полезны для больших файлов и потоков данных, когда не нужно держать все элементы в памяти. Например, можно читать файл строка за строкой и обрабатывать каждую отдельно. sum(x * x for x in numbers) вычисляет сумму квадратов без промежуточного списка.

Декоратор - функция, которая принимает другую функцию и возвращает обертку. Он может добавлять логирование, проверку доступа или измерение времени. Контекстный менеджер с with выполняет подготовку и гарантирует завершение работы с ресурсом, например закрытие файла.
