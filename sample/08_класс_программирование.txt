8 класс. Первые программы и Python.

Программа - алгоритм, записанный на языке программирования. В Python команды обычно выполняются сверху вниз. Переменная связывает имя со значением. Оператор присваивания записывается знаком =, а проверка равенства - двойным знаком ==. Функция print выводит текст, функция input читает строку с клавиатуры.

Основные типы данных Python: int для целых чисел, float для вещественных, str для строк, bool для True и False. Функция type показывает тип значения. Если число пришло через input, оно пока является строкой; для вычисления его можно преобразовать функцией int или float. Нельзя складывать число и строку без преобразования.

Условие if выполняет блок, если выражение истинно. elif проверяет другое условие, else выполняется, если предыдущие условия ложны. Отступы в Python определяют границы блока; обычно используют четыре пробела. Цикл for перебирает элементы, а range(5) дает числа от 0 до 4. Цикл while работает, пока условие истинно.

При отладке сначала прочитай текст ошибки и номер строки. Затем проверь значения переменных и условия. Маленькие примеры проще проверять, чем сразу большую программу.
