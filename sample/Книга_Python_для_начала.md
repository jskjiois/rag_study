# Python от первых команд до небольшого проекта

Это короткий учебник для самостоятельной работы. Его можно читать по порядку или искать ответ по вопросу в приложении. Примеры рассчитаны на Python 3. Сначала попробуй код в отдельном файле, затем измени входные данные и посмотри на результат.

## Глава 1. Как запустить программу

Программу пишут в файле с расширением `.py`. Команда `python hello.py` выполняет этот файл. `print('Привет')` выводит строку на экран. Если Python не найден, проверь установку и выбранный интерпретатор в VS Code. Для проекта лучше создать виртуальное окружение командой `py -3 -m venv .venv`. Оно хранит зависимости отдельно от других проектов. На Windows интерпретатор окружения находится по пути `.venv\Scripts\python.exe`. Файл `requirements.txt` позволяет другим людям установить те же библиотеки.

Упражнение: создай `hello.py`, выведи свое имя и номер класса. Затем запусти файл из терминала. Ошибку в имени файла или текущей папке можно заметить по сообщению `FileNotFoundError`.

## Глава 2. Переменные, ввод и типы

Переменная хранит ссылку на значение: `score = 10`. Имя должно помогать понять смысл данных. `input('Имя: ')` возвращает строку даже тогда, когда пользователь ввел цифры. Для арифметики строку нужно преобразовать: `age = int(input('Возраст: '))`. Типы `int`, `float`, `str` и `bool` обозначают целое число, вещественное число, текст и логическое значение. `type(age)` покажет тип переменной. `str(age)` превратит число в строку. Если пользователь введет слово вместо числа, `int` вызовет `ValueError`.

Операция `/` дает результат деления с плавающей точкой, `//` - целую часть, `%` - остаток, `**` - степень. Например, `17 % 5` равно 2. Для аккуратного вывода используй f-строку: `print(f'Тебе {age} лет')`.

Упражнение: запроси два числа и выведи их сумму, разность и произведение.

## Глава 3. Условия и логика

`if` проверяет условие. Если оно истинно, выполняется блок с отступом. `elif` задает дополнительную проверку, а `else` - действие для остальных случаев. Равенство проверяют через `==`, неравенство - через `!=`. Операции `and`, `or`, `not` соединяют условия. Например, `if 0 <= score <= 100:` проверяет допустимый диапазон оценки. Скобки помогают читать сложные выражения.

Отступы в Python обязательны. После строки `if score >= 60:` следующая строка должна быть сдвинута вправо, обычно на четыре пробела. Ошибка `IndentationError` означает, что границы блока записаны неправильно.

Упражнение: получи оценку от 0 до 100 и выведи `зачет`, если она не меньше 60. Для значения вне диапазона выведи отдельное сообщение.

## Глава 4. Циклы for и while

`for` перебирает элементы последовательности. Запись `for name in names:` выполняет блок для каждого имени. `range(5)` дает числа от 0 до 4, а `range(1, 6)` - от 1 до 5. `enumerate(names)` помогает получить индекс и элемент одновременно. `while` повторяет действия, пока условие истинно. Если условие никогда не становится ложным, цикл не закончится. `break` прекращает цикл, `continue` пропускает текущий шаг.

Для суммы чисел заведи накопитель `total = 0` и внутри цикла делай `total += number`. Для готового списка проще использовать `sum(numbers)`. Важны границы: `range(10)` не содержит число 10.

Упражнение: выведи четные числа от 2 до 20. Затем посчитай сумму чисел от 1 до 100.

## Глава 5. Строки и списки

Строка `str` - последовательность символов. Индекс начинается с нуля, поэтому `text[0]` дает первый символ. Срез `text[1:4]` берет символы с позиции 1 до 4 не включительно. `lower()` переводит буквы в нижний регистр, `strip()` убирает пробелы по краям, `split()` делит текст на части. Строки неизменяемы: методы создают новое значение.

Список `list` хранит упорядоченные элементы и может меняться. `items = [1, 2, 3]`, `items.append(4)` добавляет один элемент, `items.extend([5, 6])` добавляет несколько. `items.pop()` возвращает и удаляет последний элемент. `len(items)` сообщает длину. `sorted(items)` создает отсортированный список, а `items.sort()` меняет исходный.

Упражнение: введи строку, раздели ее на слова и выведи самое длинное слово. Проверь пустой ввод отдельно.

## Глава 6. Словари, множества и кортежи

Словарь `dict` хранит пары ключ-значение: `student = {'name': 'Ира', 'age': 16}`. Значение получают по ключу: `student['name']`. Метод `get('grade')` не вызывает ошибку, если ключ отсутствует, а возвращает `None` или заданное запасное значение. Метод `items()` перебирает пары ключей и значений.

Множество `set` хранит уникальные элементы. `set(words)` удаляет повторы, но не сохраняет привычный порядок. Объединение множеств записывают `a | b`, пересечение - `a & b`. Кортеж `tuple` похож на список, но после создания не меняется. Кортеж удобен для фиксированной пары, например координат точки.

Упражнение: посчитай, сколько раз каждое слово встретилось в коротком тексте. Результат сохрани в словаре.

## Глава 7. Функции и область видимости

Функция начинается с `def`. Она получает аргументы через параметры и возвращает результат через `return`. Пример: `def square(x): return x * x`. Если `return` нет, функция возвращает `None`. Параметр со значением по умолчанию записывают как `def greet(name='друг'):`. Не ставь пустой список значением по умолчанию: один и тот же список может использоваться при следующих вызовах. Вместо этого используй `None` и создавай список внутри.

Переменные, созданные внутри функции, обычно локальные. Функции легче проверять, когда они возвращают результат, а не только печатают его. Аннотации типов, например `def square(x: int) -> int`, объясняют ожидаемые данные, но не проверяются автоматически при обычном запуске.

Упражнение: напиши функцию, которая получает список чисел и возвращает его среднее. Для пустого списка реши, что функция должна вернуть.

## Глава 8. Файлы и JSON

Файл открывают внутри `with`, чтобы он закрывался автоматически. `with open('notes.txt', 'r', encoding='utf-8') as file:` открывает текст для чтения. Метод `read()` читает всё содержимое. Режим `'w'` перезаписывает файл, `'a'` добавляет в конец. Для путей удобен `Path` из `pathlib`: `Path('notes.txt').read_text(encoding='utf-8')` читает файл одной строкой.

JSON хранит данные как объекты, массивы, строки, числа и логические значения. `json.load(file)` читает JSON из файла, `json.dump(data, file, ensure_ascii=False)` записывает его. В JSON ключи объектов всегда строки. Ошибка `FileNotFoundError` означает, что путь неверный или файла нет.

Упражнение: сохрани словарь с именем и оценкой в JSON, затем прочитай его и выведи данные.

## Глава 9. Ошибки и отладка

Исключение сообщает об ошибке во время работы программы. `try` содержит опасный участок, `except ValueError` обрабатывает неверное значение, `except FileNotFoundError` - отсутствие файла. `finally` выполняется при любом исходе и подходит для освобождения ресурсов. `raise ValueError('Неверный возраст')` позволяет самому сообщить о неверном вводе. Не скрывай все ошибки через пустой `except`: так сложнее найти причину.

Сообщение об ошибке обычно содержит traceback со строками вызова. Сначала прочитай последнюю строку traceback, затем проверь указанную строку кода. В VS Code можно поставить точку останова и посмотреть значения переменных. Для проверок полезен `unittest`: тест передает функции входные данные и сравнивает результат с ожидаемым.

Упражнение: обработай ввод числа так, чтобы вместо падения программа просила повторить ввод.

## Глава 10. Классы и объекты

Класс описывает данные и поведение похожих объектов. `class Student:` создает класс. Метод `__init__` получает новый объект как `self` и записывает его атрибуты. Например, `self.name = name`. Экземпляр создают вызовом `Student('Ира')`. Метод может использовать атрибуты через `self.name` и возвращать результат.

Наследование создает класс на основе другого класса, но его не нужно использовать в каждой задаче. Часто проще передать один объект другому: это композиция. `@dataclass` из стандартной библиотеки сокращает запись классов, которые в основном хранят данные. Специальный метод `__str__` задает читаемый вывод объекта.

Упражнение: создай класс Book с названием, автором и годом. Добавь метод, возвращающий короткое описание книги.

## Глава 11. Модули, библиотеки и тесты

Модуль - файл Python, который можно подключить через `import`. Стандартная библиотека поставляется вместе с языком: `math` дает математические функции, `random` - псевдослучайные числа, `datetime` - даты, `pathlib` - пути, `sqlite3` - базу данных. Дополнительные пакеты устанавливают через `pip` и перечисляют в `requirements.txt`. Файл `.venv` в репозиторий не добавляют: окружение создают на каждом компьютере заново.

Тесты проверяют поведение без ручного запуска каждой функции. В `unittest` метод теста начинается с `test_`. Хорошо проверять обычный случай, пустой ввод и границы диапазона. Для внешнего сервиса используют подмену, чтобы тест не зависел от интернета.

Упражнение: вынеси функцию среднего значения в отдельный модуль и напиши три теста для него.

## Глава 12. Что изучать дальше

Когда основные конструкции понятны, попробуй списковые включения `[x*x for x in range(5)]`, генераторы с `yield`, декораторы и асинхронные функции с `async def` и `await`. Для алгоритмов полезно сравнивать время работы на разном объеме данных. Для веб-приложений нужно понимать HTTP и обработку запросов. Для анализа данных нужны таблицы, проверка пропусков и графики. Для работы в команде освой Git: `clone`, `add`, `commit`, `pull`, `push` и отдельные ветки.

Итоговый мини-проект: создай программу заметок. Она должна принимать текст, сохранять его в файл, искать заметки по слову и иметь тесты. Раздели ввод, хранение и поиск на отдельные функции. После этого попробуй добавить простой веб-интерфейс или поиск с языковой моделью.
