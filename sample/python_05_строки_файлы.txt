Python. Строки и файлы.

Строка str неизменяема: методы возвращают новую строку. lower() переводит буквы в нижний регистр, upper() - в верхний, strip() убирает пробелы по краям. split() делит строку на части, join(parts) соединяет части разделителем. Например, ', '.join(['A', 'B']) дает 'A, B'. replace(old, new) заменяет подстроку. find(text) возвращает позицию или -1, если подстрока не найдена.

Срез text[start:stop:step] выбирает часть строки. text[::-1] возвращает строку в обратном порядке. Для многострочного текста используют тройные кавычки. Символ \n означает перевод строки, а \t - табуляцию. В обычной строке обратный слеш вводит управляющую последовательность; префикс r перед кавычками создает сырую строку, что бывает удобно для путей.

Файл открывают через with, чтобы он закрылся автоматически. Пример: with open('notes.txt', 'r', encoding='utf-8') as file: text = file.read(). Для записи используют режим 'w', который перезаписывает файл, или 'a', который добавляет в конец. read() читает все содержимое; для больших файлов лучше перебирать строки в цикле.

Модуль pathlib дает объект Path. Path('notes.txt').read_text(encoding='utf-8') читает текст, а write_text(text, encoding='utf-8') записывает. Если файла нет, может возникнуть FileNotFoundError. Для русского текста явно указывай UTF-8, чтобы избежать проблем с кодировкой.
