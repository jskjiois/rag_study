Python. Функции и обработка ошибок.

Функция объединяет повторяющиеся действия и получает данные через параметры. Объявление начинается с def: def square(x): return x * x. return возвращает результат и завершает функцию. Если return нет, результат равен None. Параметры могут иметь значения по умолчанию: def greet(name='друг'): print(name). Изменяемые значения, например пустой список, не стоит ставить параметром по умолчанию; безопаснее использовать None и создавать список внутри функции.

Именованные аргументы позволяют явно указать параметр: greet(name='Аня'). Конструкция *args собирает дополнительные позиционные аргументы в кортеж, **kwargs - дополнительные именованные аргументы в словарь. Локальная переменная существует внутри функции. Замыкание может запоминать переменные внешней функции.

Исключение сообщает об ошибке во время выполнения. try содержит код, который может вызвать ошибку. except ValueError обрабатывает неверное значение, except FileNotFoundError - отсутствующий файл. else выполняется, если ошибки не было, finally выполняется при любом исходе. Не стоит ловить все исключения без причины: это скрывает настоящие ошибки. Оператор raise вызывает исключение явно.

Полезно возвращать из функции значение, а выводить его отдельно. Так функцию легче проверить тестом. Аннотации типов, например def square(x: int) -> int, помогают читать код, но сами по себе не запрещают передать значение другого типа.
