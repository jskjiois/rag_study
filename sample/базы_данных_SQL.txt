База данных хранит сведения так, чтобы их можно было быстро искать и обновлять. В реляционной базе сведения организованы в таблицы. Строка таблицы - запись, столбец - поле. Первичный ключ уникально определяет запись. Внешний ключ связывает запись с другой таблицей. Например, таблицы «Ученики» и «Оценки» можно связать по идентификатору ученика.

SQL - язык запросов к реляционным базам данных. `SELECT name FROM students` выбирает имена. `WHERE grade > 3` задает условие, `ORDER BY name` сортирует результат, `LIMIT 10` ограничивает количество строк. `INSERT` добавляет записи, `UPDATE` меняет их, `DELETE` удаляет. При работе из программы значения передают параметрами запроса, а не склеивают строку SQL из ввода пользователя.

SQLite хранит базу в одном файле и подходит для небольшого локального приложения. В нашем проекте SQLite хранит фрагменты конспектов, имена источников и текстовые векторы. Повторная загрузка файла заменяет его старые фрагменты.
