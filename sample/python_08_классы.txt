Python. Классы и объекты.

Класс описывает данные и поведение объектов. Объявление начинается с class. Метод __init__ настраивает новый объект, self ссылается на текущий экземпляр. Например, у класса Student могут быть атрибуты name и grade, а метод show может возвращать строку с именем. Экземпляр создается вызовом Student('Аня', 5).

Атрибут экземпляра принадлежит конкретному объекту, а атрибут класса общий для класса и его экземпляров, пока не переопределен. Наследование позволяет создать новый класс на основе существующего. Метод дочернего класса может переопределить метод родителя; super() вызывает реализацию родителя. Композиция - другой вариант: объект хранит внутри другой объект и использует его методы.

Свойство property дает управляемый доступ к атрибуту. Специальные методы меняют поведение объекта: __str__ задает удобное строковое представление, __len__ позволяет использовать len(obj), __eq__ определяет сравнение равенства. dataclass из модуля dataclasses автоматически создает часть обычного кода для класса данных.

Не всякой задаче нужны классы. Для простой обработки данных часто достаточно функций и словарей. Класс полезен, когда данные и операции над ними естественно связаны и объектов может быть много.
