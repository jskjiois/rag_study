Python. Числа, строки, логические значения и операторы.

Тип int хранит целые числа, например 12 и -3. Тип float хранит числа с плавающей точкой, например 3.14. Тип bool хранит True или False. Тип str хранит текст. Функция type(value) показывает тип значения. int('42') преобразует строку в целое число, float('2.5') - в вещественное, str(42) - в строку. Неподходящая строка при преобразовании вызывает ValueError.

Арифметические операции: + сложение, - вычитание, * умножение, / обычное деление, // целочисленное деление, % остаток от деления, ** степень. Например, 7 // 2 равно 3, а 7 % 2 равно 1. Вещественные числа могут храниться с небольшой погрешностью, поэтому сравнение результатов вычислений иногда делают с допуском.

Операторы сравнения: == равно, != не равно, < меньше, > больше, <= не больше, >= не меньше. Логические операции and, or и not объединяют условия. При выражении x > 0 and x < 10 обе части должны быть истинными. Можно записать короче: 0 < x < 10.

Строки заключают в одинарные или двойные кавычки. Их можно соединять через +, повторять через *, получать символ по индексу и срезу. f-строка вставляет значения: name = 'Аня'; print(f'Привет, {name}'). Индексация начинается с нуля, отрицательный индекс -1 выбирает последний элемент.
