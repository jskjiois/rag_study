11 класс. Алгоритмы, данные и искусственный интеллект.

Сложность алгоритма показывает, как растут затраты времени или памяти при увеличении входа. Линейный поиск в худшем случае проверяет n элементов, поэтому его сложность O(n). Двоичный поиск в отсортированном массиве уменьшает область поиска вдвое и работает за O(log n). Сортировка нужна, чтобы упорядочить данные по ключу.

Граф состоит из вершин и ребер. Он подходит для описания дорог, социальных связей и компьютерных сетей. Поиск в ширину обходит граф по уровням и находит кратчайший путь в числе ребер, если все ребра равны. Для графа с разными неотрицательными весами можно использовать алгоритм Дейкстры.

Анализ данных начинается с проверки качества набора: пропуски, ошибки и дубликаты могут исказить вывод. Среднее арифметическое чувствительно к выбросам, медиана устойчивее. Корреляция показывает связь признаков, но сама по себе не доказывает причинность.

Машинное обучение находит закономерности по примерам. Обучающая выборка служит для настройки модели, тестовая - для независимой проверки. Переобучение возникает, когда модель хорошо запоминает обучение, но плохо работает на новых данных. Языковая модель может ошибаться, поэтому важные ответы проверяют по источникам.
