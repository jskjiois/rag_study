Python. Синтаксис и первый запуск.

Python - язык программирования с динамической типизацией. Код в файле .py выполняется интерпретатором Python. Команда python script.py запускает файл, а python --version показывает версию. В проекте удобно использовать виртуальное окружение .venv, чтобы зависимости не смешивались с другими программами.

Функция print выводит значения: print('Привет'). Функция input показывает приглашение и возвращает введенную строку: name = input('Имя: '). Переменная создается присваиванием, например age = 15. Имена переменных чувствительны к регистру: age и Age - разные имена. Выбирай понятные имена и не называй переменную print или list, чтобы не затереть встроенные функции.

В Python отступы определяют блоки кода. После if, for, while, def и class ставится двоеточие. Строки внутри блока обычно сдвигают на четыре пробела. Ошибка IndentationError означает неправильные отступы. SyntaxError означает, что запись программы нарушает правила языка.

Оператор = присваивает значение, а == сравнивает значения. Для комментария в обычном Python-коде используют знак #, но исполняемые примеры здесь приведены без комментариев. Документация Python доступна через help(print) и встроенные строки документации функций.
