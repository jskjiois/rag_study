Python. Список, кортеж, множество и словарь.

Список list - изменяемая упорядоченная коллекция. Создание: numbers = [1, 2, 3]. Доступ по индексу: numbers[0]. append(x) добавляет один элемент в конец, extend(items) добавляет элементы другой последовательности, insert(i, x) вставляет по индексу. pop() удаляет и возвращает последний элемент. remove(x) удаляет первое равное значение. len(numbers) показывает длину. Срез numbers[1:3] выбирает элементы с индекса 1 до индекса 3 не включительно.

Кортеж tuple - упорядоченная неизменяемая коллекция: point = (3, 4). Его удобно использовать для фиксированной группы значений. Распаковка x, y = point присваивает значения двум переменным. Множество set хранит уникальные элементы без гарантированного порядка. Операции множеств: объединение |, пересечение &, разность -.

Словарь dict связывает ключи со значениями: student = {'name': 'Ира', 'age': 16}. student['name'] возвращает значение. get('grade', 0) возвращает запасное значение, если ключа нет. items() перебирает пары ключ-значение, keys() - ключи, values() - значения. Ключи словаря должны быть хешируемыми, например строками, числами или кортежами из неизменяемых элементов.

Для сортировки есть sorted(items), которая создает новый список, и list.sort(), которая меняет существующий. Аргумент key задает правило сортировки: sorted(words, key=len) сортирует строки по длине. Проверка x in collection ищет элемент, а в словаре проверяет наличие ключа.
