Python. Модули, пакеты и зависимости.

Модуль - файл Python с функциями, классами и переменными. import math подключает модуль, math.sqrt(9) вычисляет квадратный корень. from pathlib import Path импортирует конкретное имя. Пакет объединяет модули в папке; файл __init__.py часто обозначает пакет и может настраивать его импорт.

Стандартная библиотека поставляется вместе с Python. Полезные модули: math для математических функций, random для случайных чисел, datetime для дат и времени, pathlib для путей, json для чтения и записи JSON, sqlite3 для базы SQLite, collections для счетчиков и очередей. Случайные числа из random не подходят для паролей; для этого есть secrets.

Сторонние библиотеки устанавливают через pip. Файл requirements.txt перечисляет зависимости проекта. Виртуальное окружение создают командой py -3 -m venv .venv. После этого .venv\Scripts\python.exe -m pip install -r requirements.txt устанавливает зависимости внутрь проекта. Окружение .venv не нужно добавлять в Git; его создают заново на другом компьютере.

Конструкция if __name__ == '__main__': запускает код только при прямом запуске файла, а не при импорте. Это удобно для командной строки и проверок. Циклические импорты между модулями обычно указывают на неудачное разделение кода.
