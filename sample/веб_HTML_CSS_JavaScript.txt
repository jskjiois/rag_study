Веб-страница состоит из структуры, оформления и поведения. HTML задает элементы: заголовки, абзацы, ссылки, формы и кнопки. CSS задает цвета, размеры, отступы и расположение. JavaScript реагирует на события пользователя и может отправлять запросы серверу.

Форма позволяет получить вопрос пользователя. При отправке формы JavaScript может выполнить `fetch('/ask', {method: 'POST', body: ...})`. Сервер получает запрос, ищет ответ и возвращает JSON. Страница показывает ответ и источники. Важно отображать пользовательский текст как текст, а не вставлять его как HTML, чтобы избежать выполнения нежелательного кода.

Адаптивная верстка помогает странице работать на узком экране. У элементов должны быть понятные подписи, достаточный контраст и возможность управления с клавиатуры. Сервер не должен открывать доступ ко всем файлам компьютера только ради отображения страницы.
