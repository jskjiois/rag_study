# Помощник по конспектам информатики

RAG-приложение отвечает на вопросы по информатике 5-11 классов и Python и показывает источники. В `sample` лежат конспекты и краткий учебник Python. Можно добавлять свои TXT, MD, DOCX и PDF.

## Что находится в репозитории

Исходный код, конспекты, тесты, инструкция `Команды запуска.txt` и общий Word-отчёт в `docs`. Папки `.venv`, базы `data/index.sqlite` и модели Ollama здесь нет: они создаются или загружаются на компьютере пользователя.

## Первый запуск на Windows

1. Установи Python 3 с командой `py` и Ollama.
2. Скачай репозиторий, открой папку `rag_study` в VS Code и запусти терминал PowerShell.
3. Выполни `.\start.ps1`.

Скрипт создаст виртуальное окружение, установит библиотеку для PDF, запустит Ollama, загрузит модель `qwen2.5:3b`, обработает конспекты и проведёт тесты. После этого появится строка `Вопрос:`. Пиши вопросы, для завершения введи `выход`.

Для первого запуска нужен интернет: модель скачивается отдельно. Если PowerShell блокирует скрипт, выполни `Set-ExecutionPolicy -Scope Process RemoteSigned` в этом терминале и повтори `.\start.ps1`.

## Дополнительно

Для веб-интерфейса выполни `.\.venv\Scripts\python.exe web.py` и открой `http://127.0.0.1:8765`. Сервер доступен только на этом компьютере. Подробности есть в `Команды запуска.txt`.

`app.py` принимает команды, `rag_core.py` загружает документы и ищет фрагменты, `tests` содержит проверки. Индекс сохраняется в `data/index.sqlite`.
