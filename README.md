# Помощник по конспектам информатики

RAG-приложение для вопросов по информатике 5-11 классов и Python. В папке `sample` лежат конспекты и собственный краткий учебник Python. Свои TXT, MD, DOCX и PDF тоже можно загрузить.

Открой эту папку в VS Code и выполни `.\start.ps1` в терминале PowerShell. После демонстрации появится строка `Вопрос:`. Пиши вопросы, пока не введёшь `выход`. Если в конспектах нет подходящего источника, модель отвечает отдельно и честно отмечает, что ответ без источника. Подробности есть в файле `Команды запуска.txt` в корне архива.

Для веб-интерфейса выполни `.\.venv\Scripts\python.exe web.py` и открой `http://127.0.0.1:8765`. Сервер слушает только этот компьютер.

`app.py` принимает команды, `rag_core.py` загружает документы и ищет ответ, `tests` содержит проверки. Индекс создаётся в `data/index.sqlite`.
