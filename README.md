# Помощник по конспектам информатики

Приложение использует локальную модель Qwen 2.5 3B и библиотеку учебных материалов. По умолчанию работает автоматический режим: сначала выполняется поиск по библиотеке; если подходящие фрагменты не найдены, программа явно сообщает об этом и автоматически передаёт вопрос Qwen без конспектов. Если материалы найдены, Qwen формирует ответ с приоритетом этих материалов. Режим `/ai` отключает поиск по библиотеке, `/rag` ищет материалы и передаёт их Qwen, `/auto` возвращает автоматическую схему. В `sample` лежат конспекты и краткий учебник Python. Можно добавлять свои TXT, MD, DOCX и PDF.

## Первый запуск на Windows

1. Установи Python 3.9 или новее и Ollama. При установке Python нужна команда `py` или `python` в терминале.
2. Распакуй ZIP в любую папку.
3. Найди файл start.cmd в распакованном проекте и открой его двойным щелчком.

`start.cmd` запускает проект без настройки политики PowerShell. При первом запуске он создаёт `.venv`, устанавливает библиотеку для PDF, запускает Ollama и скачивает модель `qwen2.5:3b`. Для скачивания модели нужны интернет и свободное место. Затем загружаются конспекты и появляется консольный чат. Для завершения введи `выход`. По умолчанию работает автоматическая схема «сначала библиотека, затем ИИ»: при найденных материалах Qwen отвечает с опорой на них, а при отсутствии подходящей информации программа выводит сообщение о переключении и обращается к Qwen напрямую. Команда `/auto` включает эту схему, `/ai` запускает прямой диалог с моделью без поиска по библиотеке, `/rag` выполняет поиск по библиотеке и передаёт подходящие фрагменты Qwen. Команда `/new` очищает историю диалога.

В VS Code открой папку с start.cmd и выбери «Терминал → Выполнить задачу → Запустить помощника».

## Если что-то не запускается

- Python или Ollama не найдены - установи их, закрой и снова открой VS Code, затем повтори запуск.
- Модель не скачалась - проверь интернет и свободное место, затем повтори запуск.
- Папка `.venv` повреждена - удали её и повтори запуск: скрипт создаст новую.
- Кнопка Run на `app.py` не запускает проект целиком. Для обычного запуска используй `start.cmd`.

## Что входит в проект

В репозитории есть код, конспекты, тесты, инструкция `Команды запуска.txt` и общий Word-отчёт в `docs`. Окружение `.venv`, база `data/index.sqlite` и модель Ollama создаются или скачиваются на компьютере пользователя.

Для веб-интерфейса после первого запуска выполни `.\.venv\Scripts\python.exe web.py` и открой `http://127.0.0.1:8765`. Веб-чат также работает непосредственно через Qwen и учитывает последние сообщения диалога. Сервер доступен только на этом компьютере.

## Точное выполнение запросов

Qwen получает строгие инструкции: сохранять явно указанные слова, числа, строки и порядок данных, не додумывать условия и не заменять задачу похожей. Для более стабильных ответов генерация настроена на низкую температуру. Простая явная просьба написать Python-код для соединения двух строк обрабатывается точным шаблоном: исходные строки подставляются без исправлений и соединяются через `+`.

Для остальных запросов продолжает работать обычная схема проекта: сначала поиск в библиотеке, затем автоматический переход к Qwen, если подходящих материалов нет.
