Запуск RAG Study на macOS

1. Установите Python 3.9 или новее и Ollama. Поместите Ollama в папку «Программы».
2. Откройте start.command двойным щелчком в Finder. При первом запуске
   нужны интернет и свободное место для модели qwen2.5:3b и пакетов Python.
3. Когда откроется консольный чат, введите вопрос. Для выхода введите «выход».

Запуск из Терминала

cd "$HOME/Downloads/rag_study-main"
./start.command

Если Терминал сообщает «Permission denied», выполните chmod +x start.command
и повторите запуск. Чтобы запустить скрипт через Bash, введите bash start.command.

Другие режимы

./start.command demo   — демонстрация, затем консольный чат
./start.command web    — веб-чат по адресу http://127.0.0.1:8765

Веб-чат общается с моделью напрямую. Для остановки нажмите Ctrl+C.
В консольном чате /auto включает автоматический режим, /rag — поиск
по учебным материалам, /ai — прямой диалог, /new — новый диалог.

Учебные материалы хранятся в папке sample. Можно добавить TXT, MD, DOCX и PDF.
Окружение для Mac создаётся в .venv-mac.
